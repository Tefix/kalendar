Mis on arvutusväli?

Arvutusväli (Custom Calculated Field) on MS Projecti kohandatud veerg, mis arvutab väärtuse automaatselt valemiga. Sarnaselt Exceli lahtritega saad kasutada projektivälju, funktsioone ja matemaatilisi tehteid — tulemus uueneb automaatselt projektiplaanis.

Samm 01

Ava Custom Fields parema klikiga

Kiireim viis Custom Fields aknani jõudmiseks on paremklõps veeru päisel.

  1. Mine Gantti diagrammi vaatesse
  2. Tee paremklõps mõnel veeru päisel (nt Cost)
  3. Avaneb kontekstimenüü — vali Custom Fields
  4. Võid ka minna Project → Properties → Custom Fields
💡 Kontekstimenüüs näed ka Insert Column — seda läheb hiljem vaja, et arvutusväli Gantti tabelisse lisada.
Samm 02

Custom Fields aken

Custom Fields aknas näed kõiki saadaolevaid kohandatavaid välju — Number, Cost, Text, Date ja Flag tüübid.

  1. Veendu, et valitud on Task (mitte Resource ega Project)
  2. Muuda Type rippmenüüst — vali Cost
  3. Näed loendit: Cost1, Cost2, Cost3 … — vali Cost1
  4. Soovi korral nimeta ümber: kliki Rename… → sisesta nt Kulu päevas
  5. Järgmisena kliki Formula… nupul

Samm 03

Kliki Formula…

Custom attributes jaotises on kolm valikut — None, Lookup ja Formula. Vali Formula, et sisestada arvutusvalem.

  1. Custom Fields aknas leia jaotis Custom attributes
  2. Vali raadionupp Formula (vaikimisi on valitud None)
  3. Kliki nupul Formula…
  4. Avaneb valemiredaktor aknas "Formula for 'Cost1'"
  5. Näed tühja valemirida: Cost1 =
Valemiredaktori nupud
+ - * / & MOD ^ ( ) = <> < > AND OR NOT
Insert: Field ▾ | Function ▾ | Import Formula…
🛠 Kasuta Field nuppu väljade lisamiseks (nt [Cost], [Duration]) ja Function nuppu funktsioonide jaoks (DateDiff, IIf jne).
Samm 04

Sisesta valem

Meie näites jagame ülesande kogukulu kestusega — saame keskmise kulu päeva kohta.

  1. Valemiredaktoris kliki Field ▾ → Task → Cost — lisatakse [Cost]
  2. Kliki jagamismärki / tööriistaribalt
  3. Kliki Field ▾ → Task → Duration — lisatakse [Duration]
  4. Valem on nüüd: [Cost] / [Duration]
  5. Kliki OK — Project kinnitab süntaksi
  6. Teine OK Custom Fields aknas
⚠️ Valemi salvestamisel kirjutatakse Cost1 välja kõik senised väärtused üle. Kasuta kindlasti tühja välja — Cost1…Cost10 on tavaliselt tühjad.
Kasulikud valemid
Kulu päevas (meie näide)
[Cost] / [Duration]
Jagab kogukulu kestusega — kulu ühe päeva kohta
Päevad tähtajani
DateDiff("d", Now(), [Finish])
Positiivne = päevi jäänud, negatiivne = hilinemisel
Hilinemine baasjoone suhtes
DateDiff("d", [Baseline Finish], [Finish])
Kui palju päevi hilinetud võrreldes algplaaniga
Ülejäänud töö %
100 - [% Complete]
Kui suur osa tööst on veel tegemata
Samm 05

Lisa veerg Insert Column kaudu

Pärast valemi loomist lisa Cost1 veerg Gantti tabelisse, et tulemusi näha.

  1. Mine Gantti diagrammi vaatesse
  2. Tee paremklõps veeru päisel, mille kõrvale soovid veergu lisada
  3. Vali Insert Column
  4. Kirjuta otsingusse Cost1 (või oma ümbernim "Kulu päevas")
  5. Veerg ilmub kohe — näed arvutatud väärtusi kõikide ülesannete juures
👆 Veergu saad lohistada soovitud asukohta. Kliki päisel ja tiri paremal asetsevale kohale — nt otse Cost veeru kõrvale.
