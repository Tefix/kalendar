Diagrammid ProjectLibres

ProjectLibre loob diagrammid automaatselt — sisesta ülesanded, kestused ja sõltuvused ning tarkvara joonistab visuaalid ise. Saadaval on: Gantt Chart, Network Diagram, WBS (tööjaotusstruktuur), Resource Histogram ja Task/Resource Usage vaated.

Samm 01

Gantti diagramm — põhivaade

Gantti diagramm on ProjectLibre vaikimisi vaade — vasakul ülesannete tabel, paremal ajariba diagramm koos sõltuvuste joontega.

  1. Ava ProjectLibre — Gantti diagramm on vaikimisi vaade
  2. Vasakul on ülesannete tabel: nimi, kestus, algus, lõpp, eelkäijad, ressursid
  3. Paremal on ajariba: sinised ribad = ülesanded, must romb = milestone
  4. Kokkuvõtteülesanded (summary tasks) on tumesinised ribad
  5. Nooled ülesannete vahel = sõltuvused (Finish-to-Start)

Samm 02

Gantti vormindamine

Gantti diagrammil on eraldi Format vahekaart, kus saad muuta ribade värve, lisada kritiilist teed ja valida stiili.

  1. Gantti diagrammis avaneb automaatselt Gantt Chart Format vahekaart
  2. Bar Styles grupis märgi Critical Tasks — kriitilise tee ülesanded muutuvad punaseks
  3. Gantt Chart Style — vali 16 valmis värviteema hulgast
  4. Veergude lisamiseks kliki Insert Column → vali soovitud väli
  5. Baseline märkimine kuvab algsed planeeritud ribad hallina
🎨 Critical Tasks linnuke on väga kasulik — kriitilised ülesanded (ilma ajapuhvrita) muutuvad punaseks ja näed kohe, millised ülesanded mõjutavad projekti lõpukuupäeva.
📋 Gantti vaates saad lisada veerge: paremklõps veeru päisel → Insert Column → vali nt Cost, Work, % Complete.
Näide

Gantti diagramm päriselt

Nii näeb välja täielik projekt Gantti diagrammis — ülesannete tabel vasakul ja ajariba paremal.

Samm 03

Network Diagram avamine

Network Diagram kuvab kõik ülesanded karpidena ja sõltuvused nooltena — ideaalne kriitilise tee visualiseerimiseks.

  1. Mine menüüribale ja kliki vahekaardil View
  2. Task Views grupis kliki Network Diagram
  3. Kõik ülesanded kuvatakse ristkülikutena — sees: nimi, ID, algus, lõpp, kestus
  4. Punased karbid = kriitilise tee ülesanded
  5. Roosad karbid = hilinemisel olevad ülesanded
  6. Kokkuvõtteülesanded kuvatakse trapetsi kujul vasakul

Samm 04

Network Diagram — sõltuvused lähivaates

Lähivaates on selgelt näha ülesannete numbrid, sõltuvuste nooled ja kriitilised ülesanded punasena.

  1. Kriitilised ülesanded (nt 15, 16) on punasega — nende hilinemine lükkab projekti lõppu
  2. Ristiga karbid (8, 10, 11, 23, 24) = lõpetatud ülesanded
  3. Nooled lähevad vasakult paremale = Finish-to-Start sõltuvused
  4. Trapetsid (1, 7, 14, 22) = kokkuvõtteülesanded / faaside pealkirjad
  5. Milestone kuvatakse kuusnurksena (nt ID 25)
🔍 Suurtes projektides kasuta View → Zoom et suurendada/vähendada Network Diagrammi. Ctrl+Scroll toimib samuti.
Samm 05

Muud vaated ja diagrammid

Lisaks Ganttile ja Network Diagrammile pakub ProjectLibre veel mitmeid vaateid ressursside ja kasutuse analüüsiks.

📊 WBS (Work Breakdown Structure)

Hierarhiline puu ülesannete jaotusest. View → WBS

📈 Resource Histogram

Tulpdiagramm ressursside koormusest aja lõikes. View → Histogram

📋 Task Usage

Ülesanded vs töötunnid päevade kaupa. View → Task Usage

👥 Resource Usage

Ressurss vs ülesanded — kes teeb mida. View → Resource Usage

💡 Resource Histogram on eriti kasulik ressursikoormuse kontrollimiseks — punane tulp tähendab ülekoormust (ressurss on planeeritud rohkem tööd kui mahub).
Samm 06

Diagrammi printimine ja eksport

Valmis diagrammid saab printida, eksportida PNG/PDF-ina või kopeerida teistesse rakendustesse.

Eksportimise võimalused

🖨️
File → Print — prindi Gantt või Network Diagram paberile või salvesta PDF-ina
📐
Printimisseadetes vali Landscape (rõhtpaigutus) — diagrammid mahuvad paremini laiusesse
💾
File → Save As → vali .mpp formaat — avad MS Projectis, või .pod ProjectLibre natiivselt
📊
Gantti diagrammi saad kopeerida ekraanipildina ja kleepida PowerPointi või aruandesse
